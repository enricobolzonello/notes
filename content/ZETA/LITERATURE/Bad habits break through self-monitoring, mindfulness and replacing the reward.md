Five mechanisms to break bad habits:
- **self-monitoring**
- **mindfulness**
- **coping planning**
- **replacement rewarding** habit
- change the **environment**

# See also 
- [[Capitolo 6 - La Motivazione é Sopravvalutata, l’Ambiente é piú Importante]] — environment change is the most powerful lever: if the cue disappears from the context, the habit loop never starts 
- [[Capitolo 7 - Il Segreto per l’Autocontrollo]] — self-control is not about willpower but about designing the environment so the bad habit is invisible 
- [[Non possiamo eliminare i bias, possiamo solo riconoscere le situazioni a rischio]] — self-monitoring and mindfulness are the same strategy applied to habits: recognise the situations where the error is likely and increase vigilance there 
- [[Il ciclo di feedback dall'inferno]] — bad habits often persist as feedback loops; replacement with a rewarding habit breaks the loop by satisfying the same need through a different path 
- [[Willpower Isn't Depleted — It Shifts From Control to Reward]] — coping planning is a System 2 intervention; but the deeper fix is redirecting motivation toward a replacement reward rather than relying on control
